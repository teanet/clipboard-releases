# Clipboard

Менеджер истории буфера обмена для macOS. Запоминает всё, что вы копируете: текст, ссылки, цвета,
картинки и файлы. По ⇧⌘V показывает внизу экрана ленту карточек с поиском, а выбранный элемент
сразу вставляет в активное приложение.

Здесь только сборки и список изменений, исходный код закрыт.

## Установка

1. Скачайте `Clipboard-<версия>.dmg` из [последнего релиза](https://github.com/teanet/clipboard-releases/releases/latest).
2. Откройте образ и перетащите Clipboard в «Программы».
3. Запустите Clipboard. Иконка появится в строке меню, а Dock приложение не занимает.

Нужна macOS 15.4 или новее. Сборки подписаны Developer ID и нотаризованы Apple.

## Разрешения

- **Универсальный доступ** — чтобы сразу вставлять выбранный элемент (эмуляция ⌘V). Без него
  элемент только кладётся в буфер, и ⌘V нужно нажать самому.
- **Вставка из других приложений** — если macOS спрашивает при каждом копировании, выберите
  для Clipboard «Всегда разрешать».
- **Файлы и папки → Рабочий стол** (или другая папка, куда сохраняются снимки экрана) — чтобы
  класть в буфер новые снимки и записи экрана.
- **Файлы и папки → Загрузки** — чтобы скачанные файлы появлялись в истории.

## Возможности

- Текст с форматированием, ссылки, цвета, картинки, файлы. У каждой карточки указано приложение,
  из которого скопирован элемент.
- Поиск и фильтры: закреплённые, текст, ссылки, картинки, файлы.
- Вставка как простой текст, быстрая вставка ⌘1…⌘9, закрепление.
- Текст, вставленный в Finder, становится файлом с подходящим расширением: `.json`, `.md`,
  `.csv`, `.swift`, `.py` и другие, а если формат не понятен — `.txt`. С ⌥ имя и расширение
  можно выбрать самому, и файлом текст вставится в любое приложение.
- Текстовый файл, скопированный в Finder, можно вставить его текстом: целиком (⇧↩) или выбрав
  фрагмент (⌥↩, с поиском ⌘F). Из больших файлов видны первые 10 МБ, целиком вставляются файлы
  до 20 МБ.
- Текст, скопированный из Claude Code в терминале, можно вставить без переносов, которые
  расставил терминал (⌃↩): абзацы и команды склеиваются в строку, списки остаются списками.
- Файл, вставленный в терминал, становится полным путём — его прочитает Claude Code или
  подставит shell.
- Картинку можно вставить уменьшенной, выбрав размер. Картинка, скопированная в Finder,
  вставляется файлом, несколько таких фото уменьшаются разом. Фото (JPEG, HEIC) после
  уменьшения — JPEG.
- Картинка из чата, браузера или снимок в буфер (⌃⇧⌘4), вставленные в Finder, становятся файлом
  в исходном формате: `Картинка 2026-10-15 в 07.32.10.png`.
- Видеофайл можно сжать в MP4 или превратить в GIF. Для этого нужен
  [ffmpeg](https://formulae.brew.sh/formula/ffmpeg): `brew install ffmpeg`.
- Новый снимок экрана (⇧⌘3, ⇧⌘4) или запись (⇧⌘5) сразу оказывается в буфере файлом.
- Файлы, скачанные в Safari, Telegram, Chrome и других приложениях, появляются в истории, а
  буфер остаётся прежним.
- Скопированное на iPhone или iPad через Универсальный буфер обмена помечается как «iPhone».
- Пароли из менеджеров паролей и данные из приложений-исключений не сохраняются.
- Срок хранения и максимальный размер истории настраиваются, есть пауза записи.
- Интерфейс на русском и английском — по языку macOS.

## Клавиши в панели

| Клавиша | Действие |
|---|---|
| ⇧⌘V | открыть или закрыть (настраивается) |
| ←/→, ↑/↓ | выбор карточки |
| ↩ / двойной клик | вставить |
| ⇧↩ | вставить как простой текст; текстовый файл — его текстом |
| ⌃↩ | вставить текст без переносов терминала (скопированный из Claude Code) |
| ⌥↩ | картинка или несколько фото — выбрать размер, видео — сжать или сделать GIF, текст — вставить файлом, выбрав имя и расширение, текстовый файл — выбрать фрагмент |
| ⌘C | только скопировать |
| ⌘1…⌘9 | быстрая вставка |
| ⌘P | закрепить |
| ⌘R | показать файл в Finder |
| ⌘⌫ | удалить |
| Tab / ⇧Tab | фильтр |
| Esc | очистить поиск или закрыть |

Вверху панели видно, какие клавиши работают на выделенной карточке. Карточка, файлы которой
удалены или перенесены, помечена «Файл не найден»: её можно только закрепить или удалить.

## Приватность

История хранится только на вашем Mac, в `~/Library/Application Support/net.tea-net.clipboard/`.
Приложение ничего не отправляет в сеть.
